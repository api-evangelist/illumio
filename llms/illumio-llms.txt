# Illumio

> Illumio is a Zero Trust Segmentation (microsegmentation) cybersecurity company whose Policy Compute Engine (PCE) exposes a REST API (base path /api/v2) for managing workloads, labels, security policy, rulesets, IP lists, virtual services, enforcement boundaries, and traffic/flow (Illumination) queries. Products include Illumio Core, Illumio CloudSecure, and Illumio Endpoint. Authentication is via an organization-scoped API key (key ID + secret over HTTP Basic).

## APIs

- [Illumio Core PCE REST API](https://docs.illumio.com/core/): Manage Zero Trust Segmentation objects and query traffic — base path /api/v2, org-scoped API-key auth.
